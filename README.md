## `./about`

I'm a **Backend Developer & Vibe Coder** focused on building reliable web systems and turning ideas into shipped products.

My main stack revolves around **Go**, APIs, databases, distributed-ish workloads, containers, observability, and the occasional frontend adventure.

I enjoy both sides of modern development:

- writing the code myself
- vibe-coding with AI
- understanding what the generated code actually does
- debugging it when it inevitably gets weird
- shipping the final thing

My background in software testing also means I tend to look at software from both sides:

**"Does it work?"**  
and  
**"How can I prove that it works?"**

Outside of code, I'm basically in permanent **character-development mode** — always trying to get better, not only as a developer, but as a person.

Highlights:

- Go backend with REST + gRPC services
- OpenAPI code generation
- Redis-backed asynchronous jobs with Asynq
- WebSocket-based live tracking
- Stripe Connect marketplace payouts
- S3-compatible object storage
- Next.js web application
- Android packaging through Capacitor
- Docker Compose deployment
- Prometheus + Grafana observability
